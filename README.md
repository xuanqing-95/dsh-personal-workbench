# 个人主控台 · Personal Workbench

把今天的安排、AI 的进度、每日资讯和开发项目放在一个页面。由玄清设计，运行于 DeepSeek Harness。

[安装与使用](https://xuanqing-95.github.io/dsh-personal-workbench/) · [下载版本](https://github.com/xuanqing-95/dsh-personal-workbench/releases) · [问题反馈](https://github.com/xuanqing-95/dsh-personal-workbench/issues)

当前为 **0.8.0-beta.3 公开测试版**。适配 DeepSeek Harness **0.2.2 发行线（rc.1 起）**；宿主仍处于预览阶段。本次在 macOS 独立配置验证，Windows / Linux 尚未实测。界面目前以中文为主。

## 安装

在 Harness「插件」中启用实验性的「自定义插件索引」，打开「发现 → 添加索引源」，填入：

```text
https://xuanqing-95.github.io/dsh-personal-workbench/index.json
```

搜索 **个人主控台**、**玄清** 或 **dsh-personal-workbench**，核对作者和仓库后安装，再点击侧栏「个人主控台」。**Harness 不内置索引源，需先添加上述地址才能在“发现”中搜索。**

如果没有“发现”，从 [Releases](https://github.com/xuanqing-95/dsh-personal-workbench/releases) 下载 `.tgz`，在「插件 → 添加插件」选择文件，或输入其完整本地路径。不要用 GitHub 自动生成的 Source code 压缩包代替安装包。

免费安装、使用和原样分享；请保留作者署名。源代码公开展示，本版不采用开源许可，修改后再发布等权限需另行联系作者。

## 第一次使用

安装后不会出现作者的计划、账号或日报。今日计划可以直接添加、勾选；点 Data 旁的「聊聊」，使用你在 Harness 配置的模型。首次进入主对话时如提示“选择工作区”，请先选自己的工作区。需先完成 Harness 的模型设置；插件不提供共享账号或免费模型额度。

可以直接对助手说：

- “把明天下午准备演示加入我的计划，预计 2 小时。”
- “把当前项目加入主控台，关联 GitHub 仓库和当前对话。”
- “给这个项目记一个想法：下一版增加快捷键。”
- “将这份已经完成的日报放到主控台，第一条是头条，其余作为简讯。”

AI 会使用插件工具读取和记录信息。若未出现，先在原聊天查看是否实际调用成功，再刷新主控台；聊天中说“记好了”不代表工具已保存。

## 功能

| 区域 | 行为 |
| --- | --- |
| 每日 AI 日报 | 自己的头条、摘要、HTTPS 配图和最多五条简讯；按日期阅读。默认显示最近已发布的一期，选择今天时会如实显示尚未发布。配图保持比例，加载失败保留文字。 |
| Data 助手 | 独立的 Harness 聊天，沿用自己的模型与权限；可设置角色提示词。 |
| AI Agents | 当前 Harness 配置内可读的会话、自动化状态与排期，有结果时提供对应对话入口。未连接的运营插件不虚构任务。 |
| 今日计划 | 内置个人待办，日、周、月切换；先响应勾选再保存，失败时恢复并提示。 |
| 我的项目 | 聊天收录、关联对话、记录需求；只读同步 GitHub 提交、PR 和 Release。没有笔记时不显示空的记录区。 |

五块区域都可拖动、缩放。默认按内容排版，手动调整后保留尺寸。日报收起不改变 Data 的位置，页尾保留轻量设计署名。

## 接入边界

- 日报是**你自己的内容**，不附带作者的订阅、Hermes 任务或私人日报。定期制作请让 Harness 建立自己的定时任务，在任务说明中要求完成后调用 `personal_daily_brief` 交付。插件不自动创建任务，不保证新闻来源可用。
- 本版计划保存在当前 Harness 配置，**尚未提供 Notion / 独立今日计划 App 的双向连接**。作者个人版的本机连接不属于公开包；不会用“已同步 Notion”冒充连接成功。
- GitHub 自动读取需要 Git 和已登录的 `gh`。私有仓库需要读取权限。离线保留上次内容；仓库不明确时由 AI 问清楚。提交不等于发布，不推断商店审核状态。
- Codex 关联只使用指定对话的目录元数据，不扫描其他项目或读取聊天正文。原生对话跳转目前仅支持 macOS 本机；不提供 Codex 实时运行监控。

## 更新与数据

版本在 GitHub Releases 留档，索引跟随已发布版本更新。看到新版后，在 Harness 完成安装确认。**进行中的聊天结束后再升级整个插件**，宿主升级可能重载模块。本插件不会绕过确认下载并执行远程代码。

开发时的安全 UI 更新会等待聊天和编辑空闲，保留布局、日期与收起状态；这不代表互联网自动安装所有新版。

任务、项目、记录和日报存在当前 Harness profile；布局、收起状态、阅读链接和助手入口在当前浏览器 / 桌面的本地存储。卸载不会主动清空记录；清理 profile 或浏览器数据会丢失对应内容。升级前可备份自己的 profile。限额：500 条待办（含归档）、366 期日报、每项目 100 条记录；超限拒绝写入，不自动删旧数据。
