# 个人 AI 工作台

打开 DeepSeek Harness，在同一页查看今天要做的事、助手正在做什么、项目进展和模型用量。工作台由 XUANQING（玄清）设计。当前版本为 **0.8.0-beta.9**，适用于已经安装 DeepSeek Harness 0.2.2（从 rc.1 起）的用户。

## 安装到 DeepSeek Harness

在 Harness 左侧打开 **插件 → 添加插件**，复制下面这一行到安装框，点击「安装」，按提示启用。左侧出现 **个人 AI 工作台** 后即可打开。

```text
https://github.com/xuanqing-95/dsh-personal-workbench/releases/download/v0.8.0-beta.9/dsh-personal-workbench-0.8.0-beta.9.tgz
```

如果更喜欢先下载文件，可以将同一个安装包保存到电脑，再把文件完整路径粘贴到「添加插件」。直接使用下载的 `.tgz`，无需解压。[下载安装包](https://github.com/xuanqing-95/dsh-personal-workbench/releases/download/v0.8.0-beta.9/dsh-personal-workbench-0.8.0-beta.9.tgz) · [第一次使用](./START-HERE.md)

## 打开后可以做什么

| 工作台区域 | 第一次使用 |
| --- | --- |
| 今日计划 | 在卡片底部添加待办，点整行即可勾选。日、周、月可以切换，选中日期后在下方看详细安排。 |
| 你的 Data | 点击「聊聊」或顶栏「AI个人助手」，沿用 Harness 中你自己的模型与工作区。可以为助手改名、调整角色提示词，并切换黑猫或机器人。两套形象和动作均沿用 XUANQING 个人版的原始素材。 |
| AI每日精选 | 阅读你保存的头条、配图、简讯和历史刊期。可以让助手把已经写好的日报保存到工作台。 |
| AI 助手任务进展 | 查看当前可读取的任务状态、进展和成果。安装并使用兼容的运营插件后，可查看具体文案或配图进度，沿结果入口返回对应内容。 |
| 项目进展 | 将自己的项目关联到对话，记录需求并查看进展。接好 GitHub 后可以读取提交、PR 和版本。 |
| 今日用量、剩余额度 | 读取本机支持的使用记录。今日用量展示已记录的 token，剩余额度来自 Codex 返回的限额窗口。有实际记录后才会显示数字。 |

初次使用可以先加一条待办。有了自己的日报、项目或任务，卡片会逐渐填满。AI 对话使用你在 Harness 配置的模型服务和额度。想让它每天制作日报，可在自己的 Harness 中建立定时任务，并要求完成后调用 `personal_daily_brief` 保存。

## 外观与布局

点击右上角头像，在「工作台设置」中选择背景。内置柔和流动玻璃、静态浅青、晨曦柔光、青柠绿、橙光波场，也可以上传自己的图片。点击「保存」应用设置后，侧栏会同步显示新头像。点击「编辑布局」可移动或调整卡片尺寸，今日用量和剩余额度各自独立。

## 用自己的数据

日常使用只需安装插件。Notion 日计划与周任务、Hermes、Codex、已有日报目录、Chrome 商店状态和微信通知根据你自己的数据和授权接入。详情包括各服务的设置名称、读取范围和写入条件。[连接说明](./START-HERE.md#按需连接自己的工具) · [隐私与权限](./PRIVACY.md)
