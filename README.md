# 个人主控台 · DeepSeek Harness

界面规格见 [DESIGN.md](./DESIGN.md)。

在一个页面查看每日待办、AI 对话进度和你的项目。四张内容卡可以拖动、缩放并保存布局，桌宠在标题旁。

## 安装候选包

需要兼容的 DeepSeek Harness（0.2.2 发行线，从 rc.1 起）。在 Harness 打开「插件 → 添加插件」，输入 `.tgz` 文件的绝对路径，核对名称和来源，确认安装。再从侧栏打开「个人主控台」。建议在空白的测试配置中安装候选版本。

- **今日计划**：选日期、添加待办并点选完成。数据保存在当前 Harness 配置，月历的圆点表示该日有待办。
- **猫咪助手**：点小猫打开自己的 Harness 对话。对话使用 Harness 的模型、账户和权限设置。
- **项目**：关联自己的开发对话，写一句当前进展，记录和排序需求。点击「复制待办并打开对话」，把排好的需求粘贴到对话即可继续。
- **AI 进度**：查看 Harness 近期对话和可读的自动化状态。已有兼容的小红书内容生成插件并登录后，还可以查看该账户的内容制作进度。
- **日报**：保存常用的 HTTPS 阅读链接，点击进入原文。

初次打开时从空白计划和项目开始。每日任务保存在 Harness 配置中，布局、项目、进展、需求和阅读链接记在本机当前网页或桌面环境。候选版使用自身的计划库。Notion、单独的今日计划 App、Codex 和自定义日报任务的同步属于后续接入范围。

当前是安装候选，未发布到公开 npm 或社区索引。
