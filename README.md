# 个人主控台 · DeepSeek Harness

界面规格见 [DESIGN.md](./DESIGN.md)。

在一个页面查看每日待办、AI 对话进度和你的项目。四张内容卡可以拖动、缩放并保存布局，桌宠在标题旁。

## 安装候选包

需要兼容的 DeepSeek Harness（0.2.2 发行线，从 rc.1 起）。在 Harness 打开「插件 → 添加插件」，输入 `.tgz` 文件的绝对路径，核对名称和来源，确认安装。再从侧栏打开「个人主控台」。建议在空白的测试配置中安装候选版本。

- **今日计划**：选日期、添加待办并点选完成。数据保存在当前 Harness 配置，月历的圆点表示该日有待办。
- **猫咪助手**：点小猫打开自己的 Harness 对话。对话使用 Harness 的模型、账户和权限设置。
- **项目**：让 AI 在聊天中收录项目，随当前项目目录关联 GitHub 仓库，自动显示提交、合并与发布进展；保留开发对话和需求记录。点击「复制待办并打开对话」，把排好的需求粘贴到对话即可继续。
- **AI 进度**：查看 Harness 近期对话和可读的自动化状态。已有兼容的小红书内容生成插件并登录后，还可以查看该账户的内容制作进度。
- **日报**：保存常用的 HTTPS 阅读链接，点击进入原文。

初次打开时从空白计划和项目开始。每日任务保存在 Harness 配置中，项目入口和仓库关联保存在 Harness 配置中，布局、手写进展、需求和阅读链接记在本机当前网页或桌面环境。候选版使用自身的计划库。Notion、单独的今日计划 App、Codex 实时运行状态和自定义日报任务的同步属于后续接入范围。

当前是安装候选，未发布到公开 npm 或社区索引。


## 聊天收录项目与自动同步

告诉接入此插件的 AI「把这个项目加入我的项目」。AI 使用 `personal_project_shortcuts`，携带已知的 `repository`（GitHub 地址或 owner/repo）或 `projectPath`（当前具体项目的绝对目录）。Codex 对话可从该条对话的目录元数据发现远程仓库，不读取聊天正文；Harness 对话由 AI 提供自己正在使用的项目目录。

- 一次收录后，首页打开时每分钟检查；同一仓库的 GitHub 读取缓存五分钟。页面关闭时不运行后台常驻同步，下次打开继续更新。
- 优先读取 origin；不能唯一确定仓库时由 AI 在聊天中确认，不猜名称，也不扫描其他项目。尚未建立远程仓库时保留目录，后续自动重试识别。
- 同一仓库继续到新对话时保留项目 ID 和笔记关联。同仓库内两个明确不同的子目录可以分别跟踪。已有项目修改先 list，并使用 revision，避免覆盖并行修改。
- 仅读 GitHub 默认分支提交、PR 和 Releases。提交不等于正式发布，商店审核状态不由 GitHub 推断。源码未提交的编辑、未推送的本地提交不会显示为 GitHub 进展。
- 需要本机 Git 和已登录的 `gh`；读取私有仓库还需当前账号具有该仓库权限。尚未授权或网络失败时保留最后成功内容，不保存登录凭据。Codex 对话跳转当前限 macOS 本机。
